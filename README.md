# Proyecto-Plataformas-moviles
Descripción del Proyecto

Este proyecto consiste en una aplicación enfocada en la creación y exploración de bebidas, tanto estimulantes (como café o bebidas alcohólicas) como no estimulantes (mocktails y bebidas sin alcohol). Su objetivo es ofrecer una experiencia interactiva y educativa para un público interesado en el mundo del bartending y la mixología.

Funcionalidades y Servicios

Captura de imágenes:
Se integrará el uso de la cámara del dispositivo para permitir a los usuarios subir fotografías de las bebidas que preparen.

Conectividad e integración con APIs:
La aplicación hará uso de diversas APIs para obtener y clasificar bebidas. Por ejemplo, si el usuario selecciona el apartado de cócteles, se mostrarán únicamente bebidas pertenecientes a esa categoría.

Gestión de usuarios y perfiles:
Se implementará un sistema de autenticación y almacenamiento de perfiles que permitirá a los usuarios crear cuentas, iniciar sesión y guardar sus preferencias e información de manera sencilla y rápida.

Base de datos de bebidas:
Actualmente, el proyecto cuenta con un repositorio de datos de prueba, que incluye ejemplos de bebidas y sus características. En futuras versiones, se planea conectar una base de datos funcional para almacenar una mayor cantidad de bebidas junto con sus imágenes, descripciones y procedimientos de preparación.

Estado Actual del Proyecto

El desarrollo se encuentra en una fase inicial, enfocada en la estructura base del repositorio y las pruebas de integración. Los próximos pasos incluirán la conexión con APIs reales, la gestión de usuarios y la implementación de un sistema de almacenamiento persistente.
